# Sample gate interpretation

| Case | Expected teaching point |
|---|---|
| SG-001 | Clean evidence path can PASS_FOR_LIMITED_USE |
| SG-002 | High-risk path with human approval can pass gate checks |
| SG-003 | Prohibited action forces BLOCK |
| SG-004 | Missing required evidence forces BLOCK |
| SG-005 | Incomplete expected outcome → REVIEW |
| SG-006 | High-risk operational recommendation with approval and evidence can pass |

`PASS_FOR_LIMITED_USE` is not production authorisation.
